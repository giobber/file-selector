# File Selector

I was in need of a simple web dashboard that allow me to select some files and save the list of selected ones in a text file. I also want to play with HTMX and FastAPI.

## Roadmap
- [x] Show files inside a predefined folder
- [x] Allow to change the predefined folder from .env
- [x] Allow to move inside sub-folders via links and a search bar
- [x] Save list of selected files in text files

## Launch app
```bash
$ uv run uvicorn app.main:app --reload
```
